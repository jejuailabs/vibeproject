# 화면 상세 정의

공통 상태: loading / empty / ready / submitting / error / forbidden / archived.
실패 시 입력을 보존하고 재시도를 제공한다. 전송 성공은 서버 응답 기준이다. 데모용 데이터는 표시한다.

## S01. 로그인과 기수 가입

입력: Google 로그인, 초대 링크.
행동: 로그인 → 초대 유효성/대상 검증 → 가입 → 프로필 확인.
초대 만료/취소/다른 이메일은 이유와 운영자 연락 경로를 제공한다. 이메일 목록이나 다른 참가자 정보는 노출하지 않는다.
기수 미가입 Google 계정을 자동 참가자로 등록하지 않는다.

## S02. 내 대시보드

상단: 아바타, 이름, 소속 프로젝트/역할, 현재 주차.
주요 카드: 지금 활동, 해야 할 일, 환경 준비, 도움 요청.
중앙: 작성창, 내 글/관련 소식 필터, 받은 댓글.
행동: 생각 작성, 활동 참여, 프로젝트 이동, 준비 체크.
빈 상태: '첫 생각 남기기'. 프로젝트 미정이면 '아이디어 둘러보기/참여 선택'.
완료율은 필수 체크리스트 기준과 분모를 표시한다. 글 수로 역량 점수를 만들지 않는다.

## S03. 전체 대시보드

현재 활동과 일정, 고정 공지, 기수 피드.
프로젝트 보기/참가자 보기 전환. 캐릭터 카드는 이름·역할·프로젝트·공개 진행 상태.
관리자만 제출 현황, 준비 지연, 도움 요청 집계를 추가로 확인한다.
현장 공유 모드는 개인 알림/비공개 초안/팀 대화를 제외한다.

## S04. 프로젝트 대시보드

문제 한 문장, 목표, 단계, 다음 행동, 팀원 캐릭터 목록, 팀 피드.
리더는 팀 관리/단계 확정/기획 확정 행동을 가진다.
외부 참가자는 프로젝트의 기수 공개 소개·공개 데모·공개 피드백만 본다. 팀 내부 피드가 섞이지 않는다.
구성 중에는 참여 신청 목록과 역할 조율 안내를 표시한다.

## S05. 활동 상세와 현장 화면

안내, 질문, 진행 방식, 제출 양식, 마감, 공개 정책.
작성 중 임시 저장, 제출 완료 시점과 제출 버전 표시.
마감 후에는 읽기 전용. 재개 시 기존 답변으로 수정 제출 가능.
진행 화면은 QR/링크, 남은 시간, 공개 제출 카드, 집계만 보여준다.
네트워크가 끊기면 '제출되지 않음'을 명확히 표시한다.

## S06. 피드 작성과 상세

유형: 생각/질문/진행 공유/활동 정리.
필드: 본문, 선택 제목/첨부, 공개 범위, 연결 활동/아이디어/프로젝트.
글 상세: 본문, 댓글/답글, 반응, 관련 자료, 수정됨 표시.
행동: 편집, 숨김/삭제 요청, 아이디어로 발전, 결정/할 일로 연결.
공개 범위 확대는 대상과 첨부까지 미리 보여주고 명시 확인한다.
공개 대상을 줄이면 새 조회와 알림 미리보기에서도 제한을 반영한다.

## S07. 아이디어 보드와 상세

반응형 카드 목록. 정렬: 최근 변경/최신/투표 결과(허용 시).
필터: 주제, 작성자, 상태. 종료 카드는 별도 보관 필터.
상세: 문제·대상·상황·현재 방식·바라는 변화·해결 가설, 댓글, 출처, 버전, 선정 결과.
후보 상태에는 '투표 당시 내용'을 고정 표시한다.
선정 카드에는 연결 프로젝트, 미선정에는 종료 시점/결과와 재개 권한 안내.
버전 비교는 변경된 필드를 강조하고 과거 스냅샷을 직접 볼 수 있다.

## S08. 투표와 팀 선택

투표: 후보, 남은 표, 나의 선택, 마감, 제출 상태.
집계: 공개 시점 이후 후보별 표수. 개인별 선택은 표시하지 않는다.
관리: 마감/결과/최종 선정과 이유. 선정 작업은 투표와 별도 버튼.
팀 선택: 프로젝트 목표, 리더, 모집 정원, 현재 인원, 참여 신청.
신청 거절/정원 초과/이미 다른 프로젝트 참여 중인 상태를 구분한다.

## S09. 기획·문서

좌측 문서 목록, 중앙 Markdown 편집/미리보기, 필요 시 우측 댓글.
문제 → 기능 → 화면 → 디자인 → 데이터·권한 → 완료 기준의 안내 흐름.
상태: 초안/검토/확정. 최종 수정자, revision, 현재 베이스라인 표시.
동시 수정 충돌 시 내 입력/서버 최신본을 비교하고 다시 저장한다.
확정 문서는 수정 대신 새 초안으로 시작한다.
내보내기: 베이스라인 선택 → 포함 문서 확인 → MD ZIP 생성.
이전 내보내기보다 바뀐 문서를 표시한다.

## S10. 자료·회의·AI 검토

텍스트 붙여넣기, TXT/MD 업로드, 참고 링크/이미지/PDF 자료.
원본 공개 범위 선택, 관련 활동/프로젝트 지정.
AI 제안 목록: 새 카드, 기존 내용 변경, 질문, 제안된 결정.
각 제안에 원문 근거, 변경 전후, 확인 안 된 발언자 표시.
부분 승인/수정/거절이 가능하다. 승인 전 실제 카드나 확정 결정에 반영하지 않는다.
실패 시 원문과 수동 정리 경로 유지.

## S11. 개발·작업

개인 설치 준비와 프로젝트 서비스 준비를 분리.
프로젝트 서비스의 소유자/담당자, URL, 준비 상태를 표시한다.
작업 상태: todo/doing/blocked/done. 담당자·관련 기능·피드백·완료 기준.
데모 등록: 배포 URL, 설명, 연결 기획 베이스라인, 알려진 문제.
비밀 키 입력란을 만들지 않는다.

## S12. 채팅

전체/팀 채널 전환, 메시지 목록, 작성창, 답글, 멘션, 고정 공지.
읽지 않은 구간으로 이동, 메시지 직접 링크, 대화 선택과 정리.
긴 대화는 과거 페이지를 추가 로드한다.
발송 실패 메시지는 로컬 대기와 서버 저장 완료를 구분한다.
팀 미정 상태에는 전체 채팅만 노출한다.
검색은 지정한 채널·기간에 한정된 조회이며 전체 과거 검색처럼 표현하지 않는다.

## S13. 성장 이력과 발표

타임라인은 주요 버전/결정/배포를 기본 표시하고 전체 사건 보기는 별도 필터.
처음 생각과 최종 구현을 나란히 비교.
발표 카드: 프로젝트명, 팀원, 문제, 데모, 발표 자료, 핵심 변화, 회고.
리더가 공개용 전환점을 선택하고 비공개 원문을 제외한 설명을 확정한다.
발표 질문은 프로젝트에 귀속하고 답변 상태를 표시한다.

## S14. 운영

기수 설정, 구성원/역할, 활동, 투표, 프로젝트, 도움 요청, 발표 순서.
위험한 변경은 영향 범위와 이유를 표시한다.
개인 초안 열람, 모든 팀 채팅 일괄 보기, 비밀투표 개인별 내역은 제공하지 않는다.
