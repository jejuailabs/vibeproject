# 확정 방향, 제안 기본값, 미정 항목

작성 기준: 2026-10-12. 아래 '기본값'은 구현을 진행하기 위한 제안이며 사용자가 개별 승인한 값으로 간주하지 않는다.

## 사용자 요청으로 확정된 방향

- 4주 과정: 1주 문제 발견/퍼실리테이션, 2주 방식 선택·팀 구성·환경 준비, 2~3주 기획 문서, 3~4주 개발, 마지막 1.5~2시간 발표/교류.
- 오프라인을 보조하고 결과를 온라인에 정리한다.
- 패들렛 형태 아이디어 보드, 필요 시 투표, 개인/팀 프로젝트.
- 개인·프로젝트·전체 대시보드.
- 프로필 중심 개인 화면, 팀장/관리자의 캐릭터 카드 나열.
- 중앙 피드, 전체 채팅과 팀 채팅.
- 미선정 카드 종료, 선정 원본부터 최종 구현까지 이력 보존.
- 루트 main.md와 docs의 구현/디자인 문서.
- Vercel, Firebase, GitHub, Google 로그인 기반.
- 바탕화면 vibecoding2 폴더에 개발 정의 문서 작성.

## 제안 기본값

| 항목 | 초기값 | 변경 시점 |
|---|---|---|
| 표시 언어/시간 | 한국어 / Asia/Seoul | 기수 설정 |
| 진행 방식 | 혼합 | 프로젝트 선정 전 |
| 활성 프로젝트 수 | 참가자당 기수 내 1개 | 구성 시작 전 정책 확정 |
| 투표 | 후보당 1표, 인당 최대 3표, 마감 전 수정 | 라운드 개방 전 |
| 본인 아이디어 투표 | 허용 | 라운드 개방 전 |
| 결과 공개 | 마감 후 합계 공개 | 라운드 개방 전 |
| 팀 정원 | 제한 없음, 운영자가 선택적으로 설정 | 신청 개방 전 |
| 글 공개 기본 | 내 공간=비공개 초안, 팀 공간=팀, 전체=기수 | 작성 시 명시 확인 |
| 팀 채팅 | 활성 팀원만 | 지원자 초대 시 범위 명시 |
| 외부 공개 전시 | 꺼짐 | 향후 별도 기능 |
| 피드/채팅 페이지 크기 | 20/50 | 성능 검증 후 |
| 파일 | 이미지/PDF/TXT/MD, 파일당 10 MiB | 업로드 정책 |
| 녹취록 입력 | 붙여넣기 또는 TXT/MD, 200,000자 한도 | 모델 한도와 함께 조정 |
| AI 반영 | 사람 검토 필수 | 변경 불가 핵심 원칙 |
| 아바타 | 기본 캐릭터 또는 본인 이미지 | 참가자 프로필 |
| 문서 동시 편집 | revision 충돌 검사, 공동 실시간 커서 없음 | 향후 확장 |
| 보관 기간 | 운영 전 관리자가 결정 | 참가자 모집 전 |

## 구현 기준 제안

Next.js App Router, TypeScript, Firebase Auth/Firestore/Storage, Vercel 서버 명령, 앱 내부 알림.
실시간 읽기는 현재 열어둔 채팅과 한정 피드에만 사용한다.
투표·권한·버전 확정·선정·AI 반영은 서버 명령으로 실행한다.

## 미정이지만 문서/기본 UI 개발을 막지 않는 항목

참가 인원, 주차별 수업 시간, 실제 일정, 브랜드명·로고, 최종 색상, 팀 정원.
Google 로그인 자동 가입과 운영자 명단.
AI 공급자/모델/예산, 데이터 처리 안내, 운영용 서비스 계정.
참가자용 코딩 에이전트/에디터 종류와 설치 경로.
클라우드 프로젝트 리전과 결제/스토리지 사용 조건.
참고 디자인 원본 이미지 상세 검토.

## 운영 전 반드시 확정할 항목

실제 관리자, 기수 일정, 참가자 자동 가입 정책, 원본 녹취록 접근/보관 정책, 클라우드 환경, 백업/복구 절차.
AI를 켜기 전에는 공급자·비용 상한·데이터 전송 범위를 확정한다.
미정 공급자를 임의로 등록하거나 비용 발생 서비스를 자동 활성화하지 않는다.
