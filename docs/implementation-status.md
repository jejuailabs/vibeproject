## 외부 설정과 명시적 범위

AI 코드는 선택형 OpenAI 어댑터까지 구현했으나 운영 API 키·모델이 지정되지 않아 자동 분석은 꺼져 있다. 실제 공급자 호출의 품질·비용 검증은 미실행이다. 수동 녹취록 정리, 외부 AI 결과 검토, 문서 작성·내보내기는 사용 가능하다.

실제 사용자의 Google 계정으로 대화형 로그인을 대신 수행하지 않았다. 인증 초기화, 미인증 API 차단, 서버 권한과 실제 저장 동작을 검증했다.

채팅/자료는 20초 주기 조회이며 실시간 공동 편집은 아니다. 이전 아이디어·메시지·댓글·이력은 페이지로 불러온다. 현재 화면에서 추가로 불러온 페이지도 자동 갱신 시 권한을 재검증하여 유지한다.

보관 기간은 운영 정책으로 기록하며 자동 삭제 작업은 별도로 실행하지 않는다. 녹음과 음성 인식 자체는 구현 범위에 포함하지 않는다. 참가자 가입은 Google 로그인만 사용하며 별도 초대 서비스는 사용하지 않는다.

이번 Git push로 생성된 자동 배포가 READY가 되어 이전 git_info_fail 문제가 재현되지 않았다. 수동 배포도 동일 앱 코드로 READY가 되었다.

## 2026-10-17 생각 구체화 → 문제정의카드

- 생각 카드에 다섯 질문(누가 / 언제·어디서 / 막힌 행동 / 현재 해결 방법 / 빈도), 임시 저장과 이어 쓰기를 추가했다.
- 문제의 영향·해결 후 변화, 네 요소의 문제정의 문장, 세 항목의 통제범위, 문장 점검을 같은 카드에서 작성한다. 초안 저장마다 번호를 올리고 변경 이유와 질문·정의 전체 스냅샷을 보존한다.
- 보드에 생각 남김 / 구체화 중 / 문제정의 중 / 선정 준비와 다음 행동을 표시한다. 작성자만 수정하고 다른 참가자는 공개 범위에 따라 읽고 의견을 남긴다.
- 해결책을 미리 정하는 앱·기능 표현은 단어 기반 안내를 표시하며 초안 저장은 허용한다. 확정 전 사람이 직접 점검한다. AI API 호출이나 자동 판정은 추가하지 않았다.
- 새 투표와 프로젝트는 확정된 전체 공유 문제정의로 시작한다. 후보 스냅샷에 refinement를 포함한다. 기존 구형 투표는 완료할 수 있도록 호환한다.
- 프로젝트 설명은 문제정의 문장으로 생성한다. 아직 저장하지 않은 문제/사용자 문서는 원래 생각·질문 답변·초안·통제범위로 시작한다. 저장된 문서는 덮어쓰지 않는다.
- 원문 정정은 파생 카드의 새 필드·후보·이력도 비운다. 문제/사용자 문서의 원문 출처를 보존하여 정정과 내보내기 정책에 연결한다.
- 검증: 타입 검사 및 프로덕션 빌드, 단위·정책 20개, 브라우저 17개 시나리오 통과(수정 후 실패 항목 재검증 포함). 데스크톱 작성 화면과 모바일 폼을 캡처해 확인했다.
- 실제 Firebase의 별도 테스트 기수에서 임시 저장, 초안 1·2, 과거 스냅샷 재조회, 중복 요청, 비공개 접근, 타인 수정, revision 충돌, 기수 종료 차단을 검증했다. 해당 테스트 기수만 삭제했다.
