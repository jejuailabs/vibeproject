# 구현 현황 — 0.1

기준: 2026-10-12. 문서 전체 범위와 현재 구현 범위를 구분한다.

## 현재 코드

- Next.js App Router, TypeScript, Firebase Web/Admin SDK.
- Google 로그인과 사전 초대 이메일 확인, 명시 관리자 초기화 스크립트.
- 개인/전체/프로젝트 대시보드와 캐릭터형 프로필 카드.
- 생각 작성, 개인/팀/기수 범위, 댓글.
- 전체/팀 대화와 20초 갱신.
- 관리자 직접 선정/미선정 종료, 출발 아이디어가 연결된 프로젝트 생성.
- 변경 이유와 당시 내용을 보존하는 이력.
- 입력 검증, 서버 멤버십 검사, revision 충돌, 명령 멱등성.
- 별도의 /preview 가상 데이터 체험 화면.

## 문서 기본안과 구현상의 차이

첫 버전은 투표 없이 관리자 선정 흐름부터 구현했다. 정식 투표 UI라고 표현하지 않는다.
채팅은 아직 실시간 리스너가 아닌 주기 조회다.
아이디어 댓글/이력은 부모 아래 comments/history 서브컬렉션에 두어 접근 범위를 단순화했다.
기수 초대는 이메일 사전 등록 방식이며 URL 토큰 초대는 후속이다.
Next.js 서버 API를 통해 데이터를 읽고 쓰며 클라이언트 Firestore/Storage 접근은 닫는 Rules를 제공한다.
프로젝트 구성은 제안자를 리더로 한 최초 생성까지만 구현했다. 추가 팀원 신청/이동은 후속이다.
초기 조회 상한은 아이디어 100개, 그중 최근 30개 댓글·이력, 채팅 채널당 50개다. 전체 이력을 무제한 제공한다고 표현하지 않는다.

## 후속

투표/후보 고정/팀 신청, 문서 편집·베이스라인·내보내기, AI 정리, 첨부 자료, 세분화한 활동, 피드백/발표, 모바일 사용성 개선.
데이터 조회를 서버 cursor 페이지로 확장하고 Firestore Emulator 기반 통합 검증을 추가한다.
운영 전 보관 정책, 참가자 초대 UI, 속도/사용량 제한, Rules 배포, 실제 Google 로그인 E2E를 완료한다.

## 배포 런타임 호환성 수정

Vercel 런타임의 CommonJS/ESM 호환 문제를 해결하기 위해 Firebase Admin을 13.10.0으로 고정했다. UUID 11.1.1 및 gRPC 1.13.6 보안 수정 버전을 적용했다. npm audit에서 0건을 확인했으며 require(ESM)이 꺼진 조건의 서버 모듈 로드 회귀 테스트를 추가했다. GitHub와 Vercel의 저장소 연결도 완료했다.
## 최종 확인

- 배포 주소: https://vibeproject-omega.vercel.app
- 실제 배포 주소에서 샘플 작성·댓글·수정·선정·모바일 채팅 및 비인증 API 차단 E2E 4개 통과.
- 정책/런타임 테스트는 총 9개 통과.
- 서버 오류 수정 후 Firebase 웹 설정의 불필요한 줄바꿈을 제거하고 정상 번들 반영을 확인했다.
- 현재 배포는 Vercel CLI 직접 배포로 완료했다.
- GitHub와 Vercel의 저장소 연결 설정은 존재하지만, Git 기반 자동 배포는 git_info_fail 오류로 실패했다. 저장소 이름/ID/main 브랜치 일치는 확인했다. Vercel GitHub 연결 권한 또는 제공자 연결 상태의 추가 확인이 필요하다.
- 현재 CLI 인증으로 GitHub 앱 설치 범위를 조회하는 작업은 403으로 제한되어 자동 배포 원인을 더 확정하지 못했다.
- 실제 사용자 Google 로그인·운영 데이터 입력은 사용자 계정에서 확인해야 한다. 자동 계정 로그인이나 사용자 가장은 수행하지 않았다.

## Arena 디자인과 캐릭터 16종

- 개인/전체 대시보드, 팀 라인업, 프로젝트, 피드, 로그인, 채팅에 어두운 Arena 테마 적용.
- 내장 image_gen으로 생성한 캐릭터 16종. Firebase Storage 전용 경로에 PNG 원본 16개와 WebP/썸네일 32개 저장 및 URL 응답 확인. 이미지 바이너리는 Git/Vercel에 포함하지 않는다.
- 참가자가 직접 캐릭터를 선택/미리보기/저장. Firestore의 인증된 본인 members/profiles.avatar만 원자적으로 갱신한다. 다른 참가자 UID나 임의 이미지 URL 입력은 허용하지 않는다.
- 실제 Firestore 격리 테스트로 저장 유지, 타인 프로필 불변, 기존 역할/팀 불변, 멱등성, 비활성 참가자 거부를 검증했다. 테스트 문서는 정리했다.
- Firebase Auth 초기화 충돌을 발견해 firebase@12.10.0에 맞는 @firebase/app@0.14.9를 직접 고정했다. 웹 App/Auth가 같은 앱 모듈을 참조하도록 하며 Admin SDK의 의존성은 분리된다. 로그인 첫 화면을 브라우저 회귀 검사에 추가했다.
- 실제 Google 계정의 대화형 로그인은 자동 수행하지 않았다.
