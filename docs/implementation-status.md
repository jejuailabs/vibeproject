- 비공개 투표, 표 예산·자기 투표 정책, 후보 버전 고정, 집계, 이유를 남기는 최종 선정, 미선정 종료·다시 열기.

- 전체·팀 메시지, 답글, 멘션 알림, 고정, 본인 수정, 읽음, 대화→아이디어/작업/결정, 이전 기록 조회.
- Markdown 7종 템플릿·편집·저장 이력·비교·복원, 기획 기준 버전 확정, main.md + docs + 체크섬 ZIP.
- 개인·팀 준비 체크, 단계 조건, 작업 보드, 결정 기록, 외부 프로젝트 링크, 배포와 기준 버전 연결.
- 원문 직접 입력/TXT·MD 가져오기, 근거 기반 제안·부분 검토·승인, 원문 충돌·정정과 연결 자료 숨김.
- Firebase Storage 첨부, 크기·형식 검증, 범위별 다운로드, 영구 공개 링크 없는 비공개 자료.
- 발표·시연·회고, 직접 고른 공개 변화 목록, 시간 배분 일정, 배포별 피드백과 답변.
- 알림·도움 요청·신고, 운영 현황·환경 준비, 기수 공지·종료, 한시적 팀 지원 권한.
- 새 메뉴의 API와 preview가 같은 도메인 규칙을 사용한다. 실제 데이터는 항목별 Firestore 문서이며 단일 상태 JSON으로 저장하지 않는다.

## 검증 완료

- TypeScript 검사 통과.
- 단위·정책·런타임 테스트 15개 통과.
- 로컬 브라우저 E2E 10개 통과: 기존 작성/댓글/캐릭터/채팅 회귀와 활동·투표·기획·ZIP·배포·발표·모바일 자료.
- 격리된 실제 Firebase 기수에서 투표 revision 경쟁, 정원 경쟁, 선정 재전송, 문서 동시 편집 검증.
- 다른 팀 관리자·미가입자·비활성 사용자 접근 차단 검증.
- 실제 Edge 브라우저에서 Firebase 직접 업로드, 재업로드 덮어쓰기 차단, 파일 다운로드, GCS/Firebase 익명 접근 차단 검증.
- AI 모의 공급자 테스트: 도구 없는 구조화 출력, 승인 전 무변경, 작업 재전송, 문서 초안 승인, 원문 변경 충돌, 정정 파생자료 숨김.
- 테스트 데이터는 가상 기수에서 생성했고 테스트 후 해당 기수·파일만 삭제했다.
- 1440px와 390px 화면 및 모바일 오버플로 확인.
- 기존 Firestore/Storage 규칙을 원격으로 바꾸지 않았다. 두 규칙에서 앱의 서버 전용 경로가 기본 거부되는 것을 확인했다.
- Storage CORS에는 고정 앱 주소와 로컬 개발 주소의 직접 업로드 항목만 추가했으며 기존 항목을 보존했다.

## 외부 설정과 명시적 범위

AI 코드는 선택형 OpenAI 어댑터까지 구현했으나 운영 API 키·모델이 지정되지 않아 자동 분석은 꺼져 있다. 실제 공급자 호출의 품질·비용 검증은 미실행이다. 수동 녹취록 정리, 외부 AI 결과 검토, 문서 작성·내보내기는 사용 가능하다.

실제 사용자의 Google 계정으로 대화형 로그인을 대신 수행하지 않았다. 인증 초기화, 미인증 API 차단, 서버 권한과 실제 저장 동작을 검증했다.

채팅/자료는 20초 주기 조회이며 실시간 공동 편집은 아니다. 이전 아이디어·메시지·댓글·이력은 페이지로 불러온다. 현재 화면에서 추가로 불러온 페이지도 자동 갱신 시 권한을 재검증하여 유지한다.

보관 기간은 운영 정책으로 기록하며 자동 삭제 작업은 별도로 실행하지 않는다. 녹음과 음성 인식 자체는 구현 범위에 포함하지 않는다. 초대 등록은 이메일 발송 기능과 구분한다.

기존 Vercel Git 자동 배포는 git_info_fail 상태이므로 Vercel CLI로 배포한다. 버전 공개와 운영 검증 결과는 아래 릴리스 기록에 추가한다.
