# 피드·댓글·채팅·알림

## 정보 구조

피드 글은 생각과 정리된 공유, 채팅은 빠른 논의, 댓글은 특정 대상에 대한 대화다.
같은 내용을 세 곳에 복제하지 않는다. 피드 이벤트는 원본을 참조하고 접근 가능한 요약만 표시한다.
기수 전체 채널 1개, 프로젝트당 팀 채널 1개를 기본으로 한다. 개인 DM은 범위 밖이다.

## 피드

유형: thought/question/progress/session_summary.
상태: draft/published/hidden. 게시물 편집 revision은 보존하되 모든 오타 수정을 주요 성장 버전으로 만들지 않는다.
공개 범위: owner/project/cohort. anonymous/internet-public은 초기 범위 밖이다.
작성 시 대상 범위는 항상 노출한다. 게시 후 범위 확대는 명시 확인과 publication 기록이 필요하다.
개인 대시보드는 내 초안과 내 공개 글, 관련 프로젝트 사건을 묶어 보되 각 범위를 표시한다.
피드 정렬은 최신순이며 알고리즘 추천이나 인기순 경쟁은 기본으로 사용하지 않는다.

## 댓글과 반응

댓글은 대상 entityType/entityId와 선택 versionId에 귀속한다.
답글은 1단계 UI로 표시하되 replyToId로 원문을 연결한다.
질문 상태: open/answered. 제안 상태: proposed/accepted/deferred/rejected.
반영된 제안에는 결정 또는 버전 ID를 연결한다.
반응은 초기 '공감' 1종, 사용자당 대상당 1회 토글이다.
부모 자료의 열람 권한이 없어지면 댓글/반응/알림에서도 본문을 노출하지 않는다.
과거 버전에 남긴 의견은 최신 버전 의견처럼 표시하지 않는다.

## 채팅

메시지: 본문, 작성자, 시각, 답글 대상, 첨부, 편집 여부.
자신의 메시지 수정은 이력을 남기고, 삭제는 tombstone 표시를 사용한다. 일반 UI에는 삭제 전 본문을 제공하지 않는다.
원본 보존 요구와 개인정보 정정/삭제 요구가 충돌하면 제한된 삭제 절차를 따른다.
고정 공지는 기수 관리자/퍼실리테이터 또는 해당 프로젝트 리더가 관리한다.
읽음 정보는 개인 lastReadAt 기준으로 제공하며 모든 사람의 개별 읽음 명단은 제공하지 않는다.
메시지 ID는 재전송에도 동일하게 유지해 중복 생성하지 않는다.
채널 멤버가 아니라면 직접 메시지 URL도 열람할 수 없다.
팀 탈퇴 시 과거 팀 채팅 접근도 회수한다. 공개 프로젝트 소개는 계속 열람 가능하다.

## 채팅에서 기록으로 전환

1. 현재 접근 가능한 메시지를 선택한다.
2. 아이디어/결정 초안/할 일/회의 정리 중 대상을 고른다.
3. AI 또는 직접 입력으로 정리한다.
4. 근거 메시지와 목적지의 공개 범위를 함께 확인한다.
5. 권한 있는 사람이 반영한다.
6. 결과와 원문 사이에 연결을 남긴다.

AI가 '결정'을 제안해도 확정 권한은 리더/관리자에게 있다.
팀 대화를 기수 게시글로 옮길 때 원문 전문을 자동 첨부하지 않는다. 검토된 공개 요약을 별도 생성하고 원본 권한은 그대로 유지한다.
정리 대상 메시지가 수정/삭제되면 근거가 변경되었음을 표시하고 중요한 승인 전 재검토한다.

## 알림

초기 유형: 멘션, 내 글의 댓글, 내 질문 답변, 참여 신청 결과, 담당 작업, 활동 시작/마감 안내, 기획 검토 요청.
알림은 앱 내부만 지원한다.
dedupeKey로 같은 사건의 중복 발송을 방지한다. 자신의 행동은 자신에게 알리지 않는다.
기본 알림 목록에는 민감한 본문을 저장하지 않고 '새 답글이 있습니다'처럼 최소 내용만 사용한다.
클릭 시 현재 권한을 다시 검사한다. 삭제/접근 철회 시 이유를 안내한다.
전체 채팅의 모든 메시지를 알림으로 만들지 않는다. 채널 음소거와 멘션 알림을 구분한다.

## 검색

Core에서는 제목/태그/작성자 필터와 현재 조회한 채팅 범위 내 검색을 제공한다.
전체 과거 채팅 전문 검색은 별도 색인 기능으로 확장하며 초기 구현에서 무제한 전체 스캔하지 않는다.
검색 결과 역시 동일 권한 정책을 사용한다.

## 관리와 복구

신고는 기수 관리자에게 해당 콘텐츠의 제한된 검토 경로를 제공한다. 전체 팀 채널을 자동 개방하지 않는다.
콘텐츠 숨김에는 관리자·이유·시각을 기록한다.
계정 탈퇴/기수 이동/권한 철회 후 클라이언트 리스너와 캐시도 정리한다.
