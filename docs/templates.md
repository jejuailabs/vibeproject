## T11. 참가자용 main.md의 필수 구성

프로젝트명, 목표, 대상 사용자, 이번 구현 범위, 기술 구성, 문서 읽는 순서, 구현 우선순위, 완료 기준, 작업 규칙, baselineId/문서 버전.

## T12. 개발 에이전트 시작 지시문

이 프로젝트의 main.md와 docs를 읽고 이번 구현 범위와 완료 기준을 확인하세요.
현재 코드와 환경을 먼저 조사하고, 이미 있는 구현을 보존하며 작업하세요.

기획에 없는 기능 확장은 보류하고, 미정 항목은 가정을 명시하세요.
외부 계정·결제·배포 설정이 필요한 경우 구현과 설정 필요 항목을 구분하세요.
작업 후 변경 사항, 검증 결과, 미완료 사항을 알려주세요.

이 지시문은 내보내는 프로젝트 내용에 맞춰 생성하며 모든 에이전트가 main.md를 자동 인식한다고 가정하지 않는다.
